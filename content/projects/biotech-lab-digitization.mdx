              <li><strong>Designed a failure-safe file workflow:</strong> Added disk-capacity checks before saving, created a recovery copy before changes, and restored the copy when an operation failed.</li>
              <li><strong>Protected data integrity:</strong> Prevented file loss when a database transaction rolled back after a file operation, reducing the risk of inconsistent database and file-system state.</li>
              <li><strong>Investigated calculation defects:</strong> Debugged formulas that behaved differently from Microsoft Excel and identified sensitivity to seemingly harmless quotes and brackets.</li>
              <li><strong>Shared and validated findings:</strong> Documented the calculation behavior, explained the implication to my manager, informed correction of affected formulas, and tested file-handling and calculation edge cases locally.</li>
