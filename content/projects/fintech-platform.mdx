            <h2 class="section-heading fw-bold mb-4">Improving the platform from codebase to runtime</h2>
            <p class="text-secondary">I worked on backend implementation, codebase modernization, and operational reliability for application components supporting the lending lifecycle.</p>
            <ul class="text-secondary lh-lg">
              <li>Mapped module dependencies and consolidated 11 fragmented repositories into 5, reducing the need to create and manually coordinate branches across every repository for each development task.</li>
              <li>Reduced dependency and version-management complexity that was making Java and Spring Boot upgrades increasingly difficult and increasing exposure to security risk.</li>
              <li>Optimized a daily scheduled job that previously took more than an hour and sometimes failed by skipping execution steps when no relevant data had changed.</li>
              <li>Implemented audit history for important tables by storing the previous and updated records as JSON together with the identity of the person who made the change.</li>
            </ul>
